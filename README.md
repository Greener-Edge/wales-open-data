# Where did Wales's emissions go?

Interactive dashboard of greenhouse gas emissions for Wales's 22 local authorities, 2005 to 2024.

Built by Greener Edge Sustainability.

## Data

- Emissions: DESNZ, UK local authority and regional greenhouse gas emissions statistics, 2005 to 2024 (June 2026), table 1.1, full dataset. Open Government Licence v3.0.
- Boundaries: ONS local authority districts via the UK-GeoJSON project. Contains OS data © Crown copyright and database right.

## Notes

- Single self-contained `index.html`, no build step. Data and boundaries are embedded.
- Driver groupings and Neath Port Talbot shares are Greener Edge calculations from the published DESNZ sub-sectors.
